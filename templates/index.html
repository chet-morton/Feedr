How the estimates work

Feed amounts are entered as-fed. Dry matter is calculated from each feed's dry-matter percentage. Crude protein, calcium, and phosphorus are calculated from the dry-matter nutrient percentages; energy is entered as Mcal/kg of dry matter. Totals are shown per animal and multiplied by group size.

Horse defaults use a broad forage/dry-matter planning reference, not a complete NRC requirement model. Sheep targets should be set for class and production stage using current extension guidance. No generic deer requirement is assumed; deer species, season, habitat, and production class materially change needs. This first version analyzes the ration you specify; it does not automatically formulate or diagnose a balanced diet.

References: University of Minnesota Extension, Hay in horse diets; Oregon State University Extension, Nutrient requirements of sheep; Penn State Extension, Pasture and hay for horses.
